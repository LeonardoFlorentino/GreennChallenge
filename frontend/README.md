# Technical Challenge – Producers Carousel

This project aims to rebuild a carousel component, prioritizing rendering stability, animation smoothness, and deterministic rotation of the displayed items.

## 🧱 Architecture

The project was structured with a focus on modular organization:

- `components/` → Reusable UI components
- `services/` → Data abstraction layer
- `types/` → TypeScript type definitions
- `styles/` → Global styling

This separation was designed to facilitate future backend integration and ensure code scalability and maintainability.

## 🚀 Technologies Used

- React
- TypeScript
- Vite
- CSS

## ▶️ How to Run

```bash
npm install
npm run dev
```
